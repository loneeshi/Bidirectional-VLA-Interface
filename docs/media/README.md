# Demonstration

[vlm-seed1.mp4](vlm-seed1.mp4) is the unedited 512 × 512, 20 fps recording from the September 14, 2026 constrained GPT–MS-HAB diagnostic. Six skill invocations produced 336 control steps; the first object was placed after step 233. The experiment ended at its six-call limit, before completing the full five-object task.

The recording shows simulation time; model calls and SSH waits are measured separately in the [evaluation report](../evaluation.md#live-vlm-protocol-diagnostic). Configuration, checkpoint hashes, and the video checksum are in the [curated result](../results/seed1-diagnostic.json).

Rendered using [MS-HAB](https://github.com/arth-shukla/mshab), [ManiSkill](https://github.com/haosulab/ManiSkill), and the upstream ReplicaCAD/Fetch assets. Those projects and assets retain their respective licenses. No model weights or source scene assets are redistributed here.
