# S1-IA：调用对齐补充实验与门的修订

2026-09-17 America/New_York；用户最新指示覆盖旧的“普通S1不足3/10就禁止任何调用对齐训练”。原始0/10不改写，旧S2启动器不直接解锁。

## 已核实与未证实

`convert_official_fetch.py` 对全部导出帧使用统一任务级instruction，窗口family仅统计；`build_native_s2_cache.py` 才保存逐窗口family/instruction。因此历史S1是普通Fetch目标域SFT，未实现调用对齐，不能称IA SFT。这符合旧S1任务级基线的实现，但把其整任务门作为一切IA训练的必要条件，混淆了评估层级。

论文[§4.2.1、§5.1及Table3](https://arxiv.org/html/2605.13119)支持将IA数据和族残差分开研究。Table3有IA SFT且无tool-family interface的一行；正文不足以直接确定该行在线指令切换实现，不能推断它必用oracle或学习进度。单bank LoRA是本项目隔离变量的实现选择，不声称就是作者该行的全部配置。DROID中间阶段仍缺失。

两处符号错误落在阶段边界，支持调用条件不足假说，但不能证明它是最大或充分根因。相同任务指令下策略仍可依据图像和本体状态控制；两帧不证明阶段信息在观测中不可辨识。普通SFT的0/10也不能由另一benchmark的92.4直接判定原因。

## 新实验定义：S1-IA（尚未训练）

- 复用冻结父轨迹划分及窗口定义；训练和验证父轨迹互斥。
- 每个调用保留g、z、父轨迹ID、起止帧和来源hash；z实际进入tokenizer。g仅审计/分桶，不进行族路由。
- 单共享LoRA bank，无学习进度损失、无工具族残差。初始化、state24、图像、动作13及训练集归一化来源均固定。
- 不只逐帧换prompt：动作chunk必须限制在当前调用[start,end)，跨调用位置全部mask。end处观测可用于未来progress监督，但不能作为有动作标签的IA训练帧；重复端点不可重复计入6835样本。
- 现有S2缓存携带端点和progress字段，需专用IA loader与测试，不能原样当普通LeRobot数据使用。
- 时间mask与micro1/accum8按诊断清单修复；同父轨迹/当前帧暴露预算，最后不足8按实际样本平均。不得把同时修改这些因素后的收益归于IA单因素。
- 若要隔离IA净效应，需共享修复后的任务级SFT对照；预算不足时先报告组合修复，不能补造消融。

## 评估分层与准入

1. 全验证集冻结推理：reach/grasp/move夹爪符号一致率、首动作13维误差、有效chunk误差及边界±2帧；原模型保持原训练指令，新IA模型使用对应窗口指令。两种条件明确记录。
2. 调用级闭环：预注册留出起点与本次z，只执行一个有界调用；仿真谓词仅评分/终止，不为策略提供特权state。必须实证能恢复调用起点；恢复失败属于基础设施失败。先报各族分母、成功、过执行和错误交接，不能以离线loss替代。
3. oracle串接仅诊断：由仿真条件切换z，标签明确oracle；清除旧动作队列。该成绩不是自主VLM成绩，也不能直接与原生单句Pick成绩混为同一协议。
4. GPT/学习进度串接是后续系统验收。学习进度不是执行IA调用级评估的先决条件。

原任务级>=3/10保留为普通SFT能力记录，不再自动阻止独立S1-IA。新的S2准入须绑定IA调用级能力报告、接口/mask检查、错误交接验证和预注册阈值；阈值在运行前冻结，当前尚未实现、未放行。Pick的三族验证不自动证明release能力。
