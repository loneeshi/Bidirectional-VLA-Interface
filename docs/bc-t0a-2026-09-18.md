# Official BC T0a diagnostic — 2026-09-18

## Question and scope

Does the released SetTable all-object BC checkpoint produce the same native
Pick Apple trajectory through official observation/action wrappers and an
independently assembled project-style BC input/action path?

This is the first bounded T0a diagnostic. It does **not** yet execute the full
project VLA harness, AC-DiT environment fork, or unmodified upstream full-suite
evaluator. Matching results clear only the measured BC path. They cannot clear
VLA-specific preprocessing, point clouds, action chunks, or normalization.
