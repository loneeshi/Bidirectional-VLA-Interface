## 两例开发集请求体与费用边界

开发集位置 5、8 的两个模型 × 五条件场景请求共 20 份，在本地按冻结 P0/P1、传感器白名单及真值消融绑定生成最终 JSON 字节并通过发送前审计。两例均无 Q2 动作，因此另用开发集位置 20、23 的真实执行动作各生成 10 份场景请求和 10 份 Q2 请求。四例共 60 份正文、`6,718,826` 字节，API 请求 0；Q2 的两例各有 11 个冻结动作。剔除 Base64 图像正文后，各请求的文字、schema 与结构 JSON 为 3,578–4,864 UTF-8 字节，仍不是 token 数。按[OpenAI 图像输入公开的 32 px patch 规则](https://developers.openai.com/api/docs/guides/images-vision)对 `detail=original` 估算，每份 128 px RGB-D 四图约 80 图像 token，256 px 四图约 308，RGB 两图约 40，加 940×430 真值图的特权消融约 584。该图像估算不含文字、schema、请求结构或模型输出；准确输入 token 需要[官方计数接口](https://developers.openai.com/api/docs/guides/token-counting)或真实调用回执，未获本批授权，故不把字节数当作 token 数或报价。

四例图像和非图像 JSON 字节估算回执 `four-dev-image-token-estimate.json` 的 SHA-256 为 `d8618432cb6feb535cb711686e59eb26484fa35209f3225bd631ccfdf8315b26`。其中位置 5、8 是原定两例场景输入先导；位置 20、23 是为了覆盖 Q2 而追加的纯 CPU 审计。

本批实际模型 API 费用为 0。两模型 800 次完整问答和任何付费计数／推理请求须另立金额、请求数和 token 上限；实验室 GPU1 批次批准不延伸为 API 许可。历史 OpenAI 与 RunPod 账单余额仍以财务总账和 provider 回执为准。
