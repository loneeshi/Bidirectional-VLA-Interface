# C2 Astra EEF tool-loop trajectory visualizations

2026-09-30 UTC; generated entirely from archived per-step `result.json` records with [visualize_eef_trajectory.py](../../../../scripts/visualize_eef_trajectory.py). CPU only: API 0, GPU 0, simulation 0. These are **evaluation-side reconstructions**, not model observations or new experiment outcomes. No scene mesh, navmesh, object truth, or third-person image is used in the plots. The base and TCP tip are shown relative to the attempt-start `base_link` when the entry qpos is archived; the generator explicitly labels its fallback when only the first recorded frame is available. The TCP is transformed from each current `base_link` using recorded robot qpos and FK. Source/result and chart hashes are recorded per case in `trajectory-manifest.json`.

The [successful E1-B regression case 5](../../../../docs/media/c2-pick-e1b-v13-2026-09-30-plan005-replay/trajectory/trajectory.html) has a [3D TCP space curve projected into the demo scene](../../../../docs/media/c2-pick-e1b-v13-2026-09-30-plan005-replay/eef-e1b-v13-plan005-tcp-3d-scene-trajectory-demo.mp4), an earlier [side-panel diagnostic](../../../../docs/media/c2-pick-e1b-v13-2026-09-30-plan005-replay/eef-e1b-v13-plan005-tcp-trajectory-demo.mp4), and an unchanged [raw action-replay video](../../../../docs/media/c2-pick-e1b-v13-2026-09-30-plan005-replay/eef-e1b-v13-plan005-recorded-action-replay.mp4). The footage is **not** from the original online Astra run; the trajectory data is from that original run.

For each case, the chart shows the base path, TCP tip path, tool-call intervals, finger opening, cumulative force and official outcome. The interactive viewer allows step scrubbing and displays a tool call's `note` only if that run archived one. Old E1-B v13 had no notes; E1-B2 guidance-v1 did. Absence of a plotted obstacle does **not** imply free space: scene geometry is deliberately excluded. The video viewer is present only for case 5; all other attempts currently have no continuous video. Future physical Astra attempts must save the video, a synchronized in-video TCP trajectory, and the separate analysis chart at run closeout under [AGENTS.md](../../../../../../AGENTS.md).
