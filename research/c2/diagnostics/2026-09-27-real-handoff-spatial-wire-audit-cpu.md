# 离线空间理解：模型请求体 CPU 审计

## 范围

此记录只验证尚未发送的请求体构造逻辑；没有真实 RGB-D 导出、模型请求或题目评分。主条件只从官方头部和手部相机的可信清单装载 PNG；仅特权消融 B 可加入显式标记的真值俯视图。

## 请求来源绑定

- 目标语义只由冻结普查结果的 `first_pick_obj_id` 经固定物体类别表生成；不传对象实例编号、世界坐标、家具真值、结局或快照哈希。
- Q2 的动作 ID 只取冻结清单中该交接确有真实执行记录的 `q2_action_ids`；没有这些动作的交接不生成 Q2 请求。
- P0/P1 文件、普查结果、审计器和请求构造器的 SHA-256 必须与输入冻结文件一致。渲染结果还须与计划位置、交接快照 SHA 和可信传感器清单 SHA 一致。
- 构造器生成 OpenAI Responses JSON 的确定字节串。审计后的内部请求与最终序列化字节逐项比较；后续发送器必须直接发送同一字节串，不能在 SDK 层重写图片或提示词。
