# 阶段 1：开发集 Q5 模型选位静态评分入口

五阶段主线仍在第 2 步。该入口只读取已落盘并与冻结请求 SHA 绑定的模型响应；本次预检未发送 API 请求、没有机器人移动或 Pick。

## 评分口径

[`score_real_handoff_spatial_q5_api_dev_cpu.py`](../../../scripts/score_real_handoff_spatial_q5_api_dev_cpu.py)读取四个开发集交接、两个模型、五条件的 40 份场景请求。未尝试、接口删失、有效回答分别计数；仅有效回答进入[冻结 Q5 静态评分器](../../../scripts/score_real_handoff_spatial_q5_cpu.py)。评分前核对请求哈希、原始 provider 响应、交接 UID／快照 SHA、渲染结果、碰撞包、官方地面网格与对应固定基线。任何来源不一致即停止。

对有效且可评分的动作，路线通过、终点完整抓取 IK 见证、距目标更近分别计数，不相乘为一个成功率。`unreachable` 因没有冻结的全场景无解证明而单列未决。固定 `forward_10` 和始终就地抓取只在相同交接上的模型可评分记录中配对；`q5_success_probability` 没有动态 Pick 真值，因此不计算准确率或 Brier，也不填实测成功。单交接静态比例的 95% 区间用冻结的 Wilson 口径。
