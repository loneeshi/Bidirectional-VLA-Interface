## 唯一 G1 拒绝及归因

第 8 号目标帧 13，从实测帧 12 开始，第一个加密点被拒：

| 项目 | 数值 | 冻结门 |
|---|---:|---:|
| 前一躯干高度 | 0.112831987 m | — |
| 选解躯干高度 | 0.003682286 m | — |
| 躯干变化 | **0.109149702 m** | ≤0.10 m |
| 手臂最大周期角差 | 0.218709845 rad | ≤0.5 rad |
| 末端位置残差 | 0.000888289 m | ≤0.002 m |
| 末端朝向残差 | 0.000196582 rad | ≤0.02 rad |

两个冻结种子（上一步、机器人休息常量）经正则求解都产生约 0.109149 m 的躯干变化。因此这是位姿满足后被连续性规则拒绝，不能称为目标不可达。

只读归因对照中，无正则 dogbox 对同一个加密点得到躯干变化 **0.013331224 m**、最大旋转差 **0.006921750 rad**，位姿残差约 1e-15，且不跳解。对照指向当前正则选解策略产生的可避免拒绝；没有替换 v3 候选、没有计入 107/108 分子，没有修改源码或验收门。见[归因数据](g1-rejection-attribution.json)。

当前冻结实现按“正则解违反位姿容差时退回无正则解”执行；本例正则解满足位姿容差，随后违反跳解阈值，故按协议拒绝。本轮没有改成“遇跳解也退回”、调权重、调阈值或删点。此证据是 CPU 选解变化，尚不是物理躯干动力学失败，不自动锁定躯干。

## 实现与冻结

- 新模块 `src/bvi/eef_tools_v3.py`：模型逆前馈、躯干梯形粗参考、实测躯干下 arm7 补偿、共享步数、闭合前对准、闭合后等待、张开执行一步、纯关节空间 return_to_rest。
- PreferredIK：dogbox，每个种子 180 次评估；previous 权重 0.005、rest 权重 0.02；位姿硬容差 0.002 m／0.02 rad；旋转跳解 0.5 rad、躯干 0.10 m。权重在首个 v3 预测前冻结，未拟合 A1 或按结果调参。
- 候选种子仅为上一步／机器人 REST，不引入教师抓取姿态作为在线种子。连续旋转关节采用最近周期表示。
- check_path 与执行共用规划函数，拒绝时不发动作、不改 qpos；跨指令边界与指令内加密点均检查跳解。
- 运行时 return_to_rest 接受官方 ee_rest/robot_rest/is_static 回调；不调用 IK，保持夹爪指令。CPU 回调以机器人指尖 link 中点估计 ee_rest，速度使用 abs(delta)×20 Hz 保守代理，不冒充官方物理 is_static。
- v1/v2 实现、FetchDeltaExecutor、keyframe_indices 和冻结 A1 模型均未修改。v2 README 只在末尾追加更正，原文前缀已核对。[保留检查](preservation-check.json)
- [冻结参数与来源 SHA-256](frozen-parameters.json)、[九个位姿矩阵](smoke-poses.json)。此为 CPU 输入冻结；没有生成用于 GPU 启动的授权部署包。
