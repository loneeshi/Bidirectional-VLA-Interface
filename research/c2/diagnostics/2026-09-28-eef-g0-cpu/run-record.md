# 2026-09-28 · C2 末端执行器 G0 / G1 验收

> **2026-10-01 用户决定：**本记录不列入 `docs/log/` 可信日志，已从 `docs/log/2026-09-28-c2-eef-g0-executor-gate.md` 移到本诊断目录，两份日志索引中的对应行已删除。这次运行测到的主要是执行器问题：冻结的 `trf` 求解器误拒可达位姿，不是对 Astra 或任务可行性的检验。下文保留原文，数字未改。

当前主线第 2 步：失效归因与接口检验。推进：恢复真实快照并补录完整教师轨迹；阻塞：冻结 IK 求解器拒绝实际可达位姿；下一门：新求解器条件的物理回放与 robot_rest 验收。

**要回答的问题**：只靠机器人运动学和官方关节控制器，能否回放 SAC 已经成功完成的 Pick？

**设置**

- 冻结 60 普查交接中按行号 `i % 3 == 0` 划分的 20 开发交接；其中 SAC 首次成功的 11 例为 G0 清单，测试集未用。
- 已进入清单位置 5、8、11。每例两次 SAC：一次恢复快照 RNG，一次恢复同一物理快照后设新 torch seed；回放取 sac0 教师。SAC 共 230 次推理；Astra / 其它 API 0 次。
- GPU1 串行，累计上限 7,200 进程秒，单进程 180 秒，修订后总进程数最多 56（含 run01 失败）。官方 `pd_joint_delta_pos`、单步上限、累计力和严格成功判定保留，底盘固定。
- 冻结 IK 使用 SciPy `trf`、最多 180 次函数评估，位置 0.002 m、朝向 0.02 rad 容差。程序逐步记录完整末端位姿、qpos / qvel、夹爪与传感器；真值诊断单列评估端。
