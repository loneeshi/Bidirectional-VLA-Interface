# v4 夹爪阶段稳定控制修复（2026-09-29 UTC）

用户在实测失败归因后指示“修复”。版本 `eef-tool-v4-damped-gripper-r1` 仅修改夹爪操作期间的关节稳定控制；不把躯干全程锁定，也不自动换 IK7 条件。v1/v2/v3、A1 模型、教师、测试位姿、验收阈值与步数均保留。

## 原因与修复

[原物理记录及控制归因](../2026-09-29-eef-tool-smoke-runtime-retry01/README.md)显示：闭合前 10 次 IK 都有解，但粗略 A1 模型的逆前馈叠加反馈导致腕弯饱和反转；躯干每步以实测高度重新设参考，预测停稳却实际振荡。仅锁躯干也不能消除腕部跟踪误差。

新增 `src/bvi/eef_tools_v4.py` 继承 v3 的规划、移动、只读路径检查与关节回休息。夹爪操作改用官方原生关节位置目标偏移：`offset = (q_ref - q) - 0.5 * control_dt * measured_qvel`，按官方 0.1 缩放转换为动作，每通道限幅 ±0.25，相邻稳定控制动作变化限幅 0.25。周期关节取最近角。这里不使用 A1 的 rho/beta 逆模型。

躯干和头部参考在夹爪指令入口固定；对准时手臂 IK 仍基于实测躯干高度实时补偿。闭合后的等待保持已达到的手臂姿态。无法对准不闭合；跳解拒绝、全局计步、官方终止保持。变化率限制覆盖本夹爪指令内部；它不声称限制前一条移动指令到夹爪指令入口的动作差。参数是首次 v4 推演前选定的工程值，结果出来后没有调参。

新物理运行器要求读取 `robot.qvel`，控制周期取 `1 / control_freq`。CPU 替代模型只能用相邻位移/0.05 s 代理速度，已明确标注。
