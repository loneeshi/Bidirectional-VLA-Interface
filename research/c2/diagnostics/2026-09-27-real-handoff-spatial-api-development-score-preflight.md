# 阶段 1：开发集 API 回执评分器的 CPU 预检

五阶段主线仍在第 2 步。本项没有模型 API 调用，也没有模型成绩。为获批后的四例开发集校准实现[纯批次评分核心](../../../src/bvi/offline_spatial_batch_score.py)与[只读回执入口](../../../scripts/score_real_handoff_spatial_api_dev_cpu.py)：入口从 60 份冻结请求清单确定应答分母，对每份已保存的原始提供商响应重新分类、核对请求哈希和结果记录，再把有效答案送入 Q1–Q4 指标函数。

汇总器分别计数未尝试、传输结果未知、模型拒绝／格式错误等接口删失、有效答案及 Q1 真值不可评；Q2 的每条实际动作以所属交接为组。Q1／Q2 报二元准确率、平衡准确率和 Brier，Q3／Q4 报多类别准确率、平衡准确率和 Brier，Q3 距离另报 MAE。多数类差距只使用该模型有有效答案的同一批样本。Q5 的静态几何评分和测试集区间仍须另行接入；这份工具不把四例开发集写成测试结论。

使用不存在的结果目录做离线预检：应答清单 60 份、记录 0 份，全部保留为 `not_attempted`，无模型指标。回执在区间实现后重新生成，SHA-256 为 `ba0c03eed4cd75a18c03018cc0c439c0f8d993815d920ae0b2449100f46c08ac`，仅存本地忽略路径 `runs/real-handoff-spatial-stage1-20260927/api-dev-score-preflight.eval-only.json`。合成测试覆盖有效与删失请求、缺失请求、重复请求、提供商原始响应被改动、传输未知；GPU／模型 API 新用量 0。

后续补入冻结的区间算法：单交接一条的准确率用双侧 95% Wilson；Q2 多动作准确率、所有 Brier、Q3 距离 MAE，以及同样本多数类准确率和 Brier 差距，按交接成组做固定种子 `20260927`、2,000 次百分位重采样。平衡准确率只在全部预定类别齐全时有点估计和条件区间；否则明确为不可评。合成测试验证两个动作来自同一交接时始终作为一个重采样单元。开发集当前无提供商响应，所以没有实际指标或区间可报。下一停止门仍是开发集 USD 3.50 独立费用授权。
