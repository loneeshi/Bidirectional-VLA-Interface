## 实现和冻结参数

独立`eef_tools_v13.py`及v13调用层、runner。每次有效工具调用（包括尝试的第一调用）先发底盘零速度，保持入口上身关节目标与原夹爪；每个转向/直行阶段前先停稳，退出也检查停稳。无效参数在前置层之前拒绝，不步进。零指令仍执行停稳。停稳采用norm(qvel[:2]) < **0.02 m/s**、abs(qvel[2]) < **0.03 rad/s**，连续**2次发零速度后的观测**满足；严格小于，停稳计入调用与官方预算。官方终止后无新动作。

`check_path`函数本身保持只读；v13统一调用层先执行并计入停稳，因此整次check_path调用可以消耗环境步。done/give_up同样走前置停稳。末端工具的旧调用预算不增加，停稳从原调用预算内扣除；底盘每次≤80步、官方≤200步。尝试起点里程计坐标原点保持冻结快照，不因停稳重新归零。

减速度只以第5/8号r3已有记录中相邻两步采样接触冲量均为0的片段拟合：v_next=rho*v+beta*u。线性rho=0.66186550，角向rho=0.03732811。取a=floor(100×0.25×(1−rho)×vmax/0.05)/100，得到**直行0.84 m/s²、转向4.81 rad/s²**。速度上限仍0.5m/s、1rad/s。未用第11号拟合；“采样无接触”不是对每个物理子步无接触的证明。

主段速度=min(vmax,sqrt(2a|e|))；尾段K=2。尾段切换距离max(2×容差,(dt/(1−rho_max)+dt)×vmax)，rho_max取上述两通道拟合的最大值，用于容纳响应迟滞与一步延迟。尾段直行约0.098935m、转向约0.19787rad，明确冻结；没有增益4。CPU过程中的失败与修订保留在[cpu-revision-history.json](cpu-revision-history.json)。接触没有进入控制条件。

无横移、路线检查或场景过滤；纯转向不输出平移补偿。每调用记录入口/出口qpos、qvel，停稳与阶段步数；每步记录指令和实测速度。新评估接触记录附scene_key、articulation_name/link_index（适用时）、entity_name和pair_index，只在评估端，不进Astra请求。
