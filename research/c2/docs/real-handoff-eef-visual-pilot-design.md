- 头/手 RGB 与深度图全部实际渲染 2048×2048，FOV=2 rad，原 PNG、detail=original，无上采样旧图、无静默降采样。完整 previous_response_id 链按交接隔离，不截断历史。
- 首轮也不给目标真值位置。新观察构造器不读取目标 actor/场景几何；语义沿用冻结类别映射。主条件不读取真值路线、不做场景碰撞过滤。
- 本修订允许在 E1-B2 尚未完整执行且未过门的情况下，完成 CPU、接口、G2 后申请独立视觉开发试点。它不补判 E1-B2 通过，也不修改其结果、删失或分母。
- 同时改变了图像、观察工具和只读开销，因此只评价整体闭环，不据此分别宣称高清、转头或去除特权坐标的因果收益。

## 冻结接口

沿用 v13 底盘刹车、停稳、限速、IK8、夹爪和关节空间回位；不原地修改历史代码，不开发新的底盘控制版本。新增 VisualTools 包装器。

| 接口 | 冻结语义 |
|---|---|
| look(pan_rad, tilt_rad) | 绝对头部关节角；pan [-1.57,1.57]、tilt [-0.76,1.45] rad。官方 body 动作通道；保持入口躯干/手臂目标和夹爪，底盘速度为零。含 v13 入口停稳最多 40 步；角度最大误差 ≤.02 rad、头部速度最大值 <.03 rad/s，连续 2 步才到位。使用已有 damped position 控制参数，不另拟合。 |
| locate_point(camera,pixel,observation_id) | head/hand，整数像素 [x,y]，左上原点、0..2047；必须最新观察，任何 qpos 变化后旧帧失效。同帧整数毫米深度→米，实际内参、URDF 相机外参→当前 base_link 表面点。返回 3×3 邻域有效深度极差；无效点返回 valid=false，不填补、不自动选像素。 |
| check_path | 当前实测姿态上的 IK/限位/连续性检查。删除新分发器中的停稳前奏；核心检查保持不变。minimum_steps 仅为理论下界。 |
| 只读与结束 | check_path、locate_point、done/give_up 都不执行环境动作、不修改执行器目标。只读调用和无效调用仍占 25 次额度；结束保留 hindsight。第一次实际运动承担入口停稳，初始化不隐藏步进。 |
| 反馈 | steps_used、settle_steps、motion_steps、steps_remaining，以及实际残差。细分逐步 trace 保存在评估侧。工具结果不向模型开放官方抓取标志、接触身份或评估标签。 |

转头后 return_to_rest 仍按官方 ee_rest、robot_rest、is_static 判据；其关节目标包含头部，但已在官方容差内时不要求精确归零。所有实际运动与停稳共享官方 200 步，官方终止立即禁止再步进。

guidance-v2 沿用 v1 的机器人常量及通用方法，改为主条件任务描述和 2048 尺寸，加入换视角、表面点含义、只读零步、理论步数下界及回位预留说明。每次调用必填 note；官方力/时间终止后的反思只告知结局和终止类别。

## 恢复与高分辨率缓存迁移

冻结快照的 FrameStack 含三帧 128 深度。按原方式恢复物理状态、控制器和官方计数后，仅以当前真实采集的 2048 深度重新填充这层未用于 Astra 的 SAC 图像缓存，防止下一次 env.step 混合尺寸。无环境步、无旧图放大；记录迁移前后形状，断言物理状态和 cached official info 不变。该缓存不是模型历史。由于观察条件有意改变，不再要求 128 SAC policy 输入 tensor 哈希与新 2048 观察相同；快照、场景、控制器、物理状态及官方计数绑定仍保留。

## CPU → GPU 接口/G2 → Astra

CPU 回执、提示、schema、预算、样本及来源哈希见 [CPU 诊断](../diagnostics/2026-09-30-eef-visual-cpu/README.md)。CPU 以替代动态和合成图片检查接口，不是实际渲染或物理成功。

GPU 接口验证独立申请：3 个样本各一进程，先恢复、真实 2048 观察及只读检查，再 look(.3,.712)、look(-.3,.412)、return_to_rest；每例仍 ≤200 官方步。每个 look ≤40、rest ≤60。逐步保存命令、qpos/qvel、保持目标、残差、停稳与运动耗步、评估接触；失败停止批次。

G2 每个初始/转头/回位观察均评估两路相机：URDF 外参与世界参考转换最大绝对误差 ≤1e-5；真值目标分割仅用于评估，比较反投影点与同像素渲染目标表面参考，每个有数据帧 P95 ≤.01 m，最大值、无效率和像素数另报。两路相机合计均须有有效目标像素，缺失阻塞。每帧门比单个合并 P95 更严格，不隐藏坏帧。此 G2 核对几何反投影和标定，不是独立的深度噪声测试。渲染位置、分割、模型矩阵只在评估模块中读取，模型主运行器不导入该模块。

接口通过后再提交 API 试点提案：GPU1 串行 3×1800=5400 进程秒，最多 78 请求；当前完整历史保守预留 USD949.1184，建议上限 USD950，未授权。该值按文本字节上界、图像 patches、所有历史最大输出和最坏 cache-write/长上下文费率计算，不是实花预测。真实使用若超过冻结输入包络即删失停止，不悄悄压缩。

普通模型任务失败按固定三例继续，基础设施/网络结果未知停止批次、保留删失、不自动重试。逐例报告严格 Pick、终止原因、首次前进距离、分段接近、观察工具使用和步数分配；失败引用 note/hindsight 与传感器/执行交叉核对，采用 AGENTS 的四类归因。同类目标歧义单列。

三例完成后才制定 H0/H1 各最多三次的独立配对重试提案，成功即停，不含 SAC 示范，不把随机重试收益冒充上下文学习。发布与测试集评估均不在本授权中。
